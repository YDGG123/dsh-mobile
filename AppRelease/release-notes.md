## 功能更新

- 双端支持在会话中选择和上传文件，查看上传进度、移除附件或重试失败上传；已发送文件以附件卡片展示。
- 双端新增独立的正文文字选择页面，支持选择、全选和复制，关闭后保留会话阅读位置。
- 双端改进 Markdown 表格阅读，支持全屏查看、旋转、复制和导出 CSV；少列表格自动铺满可用宽度，宽表格可横向滚动浏览。
- iOS 最低支持版本扩展至 16.1，并为较旧系统提供兼容界面。
- 改善 iPhone Duo 展开与闭合时的首页背景、安全区和横竖屏布局；宽屏会话提供按工作区分组的侧边栏，修复定时任务工具栏按钮挤压问题。
- 修复 iOS 首页玻璃按钮初始高亮、侧栏时钟图标大小不一致及折叠后输入框占位文字变形的问题；权限名称在空间足够时完整显示。
- 优化 Android 统一毛玻璃菜单、会话重命名和侧滑导航的交互体验。
- 改善团队会话与工作区文件浏览，修正会话 Token 用量统计显示。
- 改善 iOS 后台恢复时的连接验证、请求超时和团队面板打开体验，并提升图片发送的格式兼容性。

## 必需插件

- 必须安装 [dsh-plugin-mobile-gateway](https://github.com/Clarklevis1995/dsh-plugin-mobile-gateway) `v0.11.1` 或更高版本。
- 安装或升级后，需要完整退出并重新启动 `dsh web`。

```bash
dsh plugin --profile web add dsh-plugin-mobile-gateway@latest
```
