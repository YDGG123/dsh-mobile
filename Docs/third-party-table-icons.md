# 表格操作图标来源

- 图标库：[Tabler Icons](https://tabler.io/icons)。
- 官方矢量源：[tabler/tabler-icons](https://github.com/tabler/tabler-icons)。
- 固定版本：`a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d`。
- 复制：`icons/outline/copy.svg`，下载：`icons/outline/download.svg`，展开：`icons/outline/arrows-diagonal.svg`。
- 旋转图标按用户提供的参考图绘制：前景为横屏设备，后景为竖屏设备，后景笔画透明度为 38%。
- Android VectorDrawable 与 iOS 模板 SVG 使用相同路径、圆头和圆角连接，统一笔画为 1.75px，通过模板着色适配深浅模式。
