# 智能体头像

本套头像由本项目设计提案 01 接入，使用 12 种抽象几何结构和 12 组双色调色板，组合成 144 种本地矢量头像。原始 12 枚对应索引 0–11，其余索引按轮廓和调色板扩展。

设计稿：https://www.figma.com/design/s4A0l6vIQQwM9h2I7bx6pd?node-id=2-106

## 身份分配

- `SharedTeamStore` 使用成员会话 ID 的固定哈希选择初始轮廓，并避开本团队已分配的组合。
- 名称、模型、任务描述或成员顺序改变，不重新分配头像。暂时离开团队的成员保留原分配。
- 同一网关的分配随离线导航目录缓存，iOS 与 Android 共用分配规则，互相独立的网关目录相互隔离。
- 最多保留 4096 条分配；同一团队超过 144 条历史身份后允许复用已有组合。
- 头像只表达身份，执行状态和当前会话仍由独立文字及选中标识表达。

## 绘制与布局

- iOS：Asset Catalog 保留 SVG 矢量与原始颜色；Android：本地 SVG 解析成缓存的绘制指令。
- 不依赖远程头像服务；无需为打开团队弹层额外请求图片。
- 标准头像尺寸 32pt / 32dp；成员项统一高度，任务描述单行、尾部省略。
- 成员列表滚动区域裁剪到分隔线，上方列表和下方完整团队入口分离。

## 素材来源记录

本套 SVG 是本轮设计直接构造的几何图形，没有复制 WOOHOO、DiceBear 或 Codex 的素材文件。它们仅作为抽象头像方向的研究参考；APP 未包含这些第三方素材包。
