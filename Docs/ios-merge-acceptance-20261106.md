# iOS 合并验收清单（预案，iOSTester 2026-11-06 01:4x 落盘）

**性质**：这是**验收预案**——写的是"该怎么验"，不是"已经验过"；包出来前不含任何实测读数。
**对象**：合并分支 `merge/upstream-1.7.15`（上游 `24f12c3`→`3bf35b7`，30 提交/25 功能提交）出包后的 iOS 真机验收。
**判读纪律**：每个判据必须可判真假；失败时记录「截图 + Console 日志过滤 subsystem `ai.dsh.mobile.ios`」两条。
**装机自证**：设置 → 关于 → 当前版本应显示新构建号（1.0.0 (N)），与交付文档一致。

## A. Tailscale 内嵌隧道（全新功能，最高风险）

**怎么验**：
1. 设置页找到 Tailscale 隧道项（实读落点：`TailscaleTunnelSettings.swift` / 设置页内，包出来后按实际路径走一遍）
2. 开关打开 → 等待状态从「未连接」变为「已连接/Running」（真机走蜂窝或另一 WiFi，不要在电脑同一局域网验，否则分不清走哪条路）
3. 开启后发一条消息，看电脑端是否收到（连接真的走内网）
4. 关闭开关 → 确认连接回落到 Cloudflare 隧道（`/mgw/status` 的 connectedClients 不掉）
5. **静默失败专项**：关闭手机网络/飞行模式后再开隧道开关，观察是否有错误提示；若无任何提示且状态一直「连接中」→ 记「开了没用但也不报错」的形态与时间长度

**通过判据**：
- 开启后 ≤60s 状态变 Running（上游提交信息实测冷启动 7s，留余量）；此时发消息电脑端必收到
- 关闭后 ≤10s 回落到 Cloudflare 隧道，消息通路不断
- 失败时**必须有可见提示**（文案或状态行），「无提示地卡在连接中」判红
- 状态文案中英/中文可读，无裸 code

**失败时记**：开关状态截图 + `TunnelDiagnostics` 相关 Console 行 + 当时 `/mgw/status` 读数。

## B. 页头「两者都要」（用户拍板，出包后定去留）

**怎么验**：进任一会话页，从上到下看三个元素：①「对话|轨迹」分段按钮 ②副行（成员名等）③顶部小指示条（上游 overlay 形态）。

**通过判据**：
- 三者**同时可见**：分段按钮可点、点击后标题/内容切换；指示条随翻页变化
- **不互相挤压**：副行文字不被指示条遮盖；分段按钮不被顶进状态栏（顶部留白正常）
- 正文首行不压在分段按钮下方（布局从分段下方开始）

**失败时记**：整页截图（三元素同框）+ 指出被遮/被顶的具体元素。

## C. 引用回复（quote，上游新增）

**怎么验**：长按一条消息 → 出现「引用」动作（`:5972 UIAction "引用"`）→ 选中 → 输入框出现引用块 → 发送；再长按该消息或引用块 → 「移除引用」（`:1635`）。

**通过判据**：
- 长按出现引用入口；引用后输入框显示被引内容（CompactMessageQuote 样式）
- 发送后消息带原文；「移除引用」能清掉引用块且正文保留
- 引用不支持的消息类型（如有）不崩溃、有降级表现

**失败时记**：长按前后截图 + 崩溃时取 Console 崩溃栈。

## D. 日志导出

**怎么验**：设置 → 日志导出（`LogExportView.swift`）→ 选时间段 → 生成 → 分享。

**通过判据**：
- 选定时间段能生成文件；内容为运行日志（非空、可读）
- 分享面板正常弹出；导出的文件在电脑端可打开
- 时间段为空/无日志时有明确提示，不生成空文件也不崩溃

**失败时记**：导出页截图 + 生成的文件路径（若生成）。

## E. 生成图片预览 / 附件恢复（`60397f3`）

**怎么验**：让某个 Bot 跑一个会产生图片输出的任务（或回放历史会话里有工具产图的消息）→ 看该图片是否独立成条显示预览。

**通过判据**：
- 工具生成的图片显示为**独立条目**（不混在文本正文里）
- 同一调用的重复图片**去重**（不出现两份同图）
- 杀进程重开后该图片仍能恢复显示（附件恢复路径）

**失败时记**：图片缺失/重复的截图 + 该条消息 id。

## F. 历史分页（`fc12ae4`，先加载更早一页再展示）

**怎么验**：进长会话 → 看首屏出现耗时 → 上滑翻页数次。

**通过判据**：
- 首屏出现无异常等待（>5s 白屏判红；1-3s 内出现算过，记录实际秒数）
- 翻页时无内容跳动（已读位置不上窜下跳）；触顶自动补页正常
- 翻到列表尽头有终态提示，不死循环加载

**失败时记**：翻页过程录屏 + 每页加载耗时（录屏带时间戳）。

## G. 设置导航保持根路径（`1fdb31b`）

**怎么验**：设置 → 进入任一子页（Agent 预设/默认模型/字体大小，**应为 sheet 弹出不 push**）→ 关闭 → 再次进入其它子页 → 返回。

**通过判据**：
- 三个选项为 sheet 弹出（无推入动画、无返回按钮，`:1589` 注释口径）
- 反复进出不同子页后，返回总是回到设置根页，不跳到其它 tab/层级
- 「UI 降级」开关、Tailscale 行、网络检测四行均在设置页可见

**失败时记**：导航错层的路径复现步骤（从哪进、怎么回、落到哪）。

## H. WebRTC 连接选项（上游实验性）

**怎么验**：设置里若有 WebRTC/RTC 开关 → 打开 → 重连 → 发消息；再关闭 → 重连 → 发消息。

**通过判据**：
- 开启后连接失败时**能回落 WebSocket**，消息通路不中断（不许"开了 RTC 就死"）
- 关闭后行为与合并前一致
- 若设置里没有该开关 → 记「未暴露」，不算失败

**失败时记**：开关状态 + 重连时 Console 的连接路径行。
