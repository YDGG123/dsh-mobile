# iOS 历史阅读窗口批量补页

2026-10-21。针对已结束会话翻旧记录时，多次加载只增加工具调用数、没有增加正文的问题。

## 行为

一次触边或点击加载对应一个呈现操作。新增内容不足时，沿用同一个操作继续补取，按约两屏新增用户/助手正文的估算高度决定何时呈现。工具调用、工具结果、思考、上下文与 Markdown 分块不按独立正文计量；原始事件完整保留，仍可在过程详情中查看。

估算使用当前视口、可用宽度和字体大小，在后台计算。补取期间不更新 timeline 或已显示正文；完成后统一交给现有 UIKit 锚定、滚动条稳定与渐显流程。最终呈现确认之前，原有准入仍然有效，重复触发会被拒绝。

停止条件包括正文目标达到、历史结束、游标不再前进、失败、累计8轮补取、新增投影文本达到1,048,576个UTF-16单元或累计耗时达到2.5秒。预算在响应完成后判断，不取消已在途的网络请求。网络每轮沿用共享领域层最多2个传输页的策略；这是呈现层的阅读预算，没有改共享分页 cursor 逻辑。

本轮阅读批次中的较早网络页最多120个事件、本地页最多160个事件。首屏仍用原有预算。进行中的流式会话、搜索上下文继续走原有路径，本轮集中修复截图所示的已结束普通会话及其可衔接的Room缓存页。

## 验证

125项 iPhone 17 / iOS 26.5 模拟器测试全部通过，包括10项新增测试：6项阅读预算策略、3项网络批次集成、1项真实Room离线集成。其余覆盖原有历史呈现准入、实际UICollectionView锚点与滚动条、初始/历史渐显、Markdown、静态后台准备、首屏/订阅和完整Room缓存测试。

网络测试连续送入90个工具调用，验证只开始一次呈现操作、补取期间timeline版本不变、取得9条正文后统一发布，并等待实际呈现确认后结束。短页测试累计20条正文后统一发布。Room测试保留400个事件：首屏80个事件，之后连续读取两个160事件页；首个旧页纯工具调用时自动继续，最终保留339条工具记录和60条较早用户消息。

签名验证及模拟器实际安装的主程序、Debug dylib哈希核验通过。本轮起点的449个Android/共享源码文件指纹未变。上述结果属于模拟器功能与布局回归，不是新的真实网关延迟或GPU FPS测量。

早期失败记录已保留：首次新增Swift测试字典表达式触发编译诊断问题；连续响应夹具曾在前页后台解析完成前送入下一页，与真实请求/响应时序不符，现已等待前页归并完成。最终结果来自同一源码版本的一轮完整125项回归。
