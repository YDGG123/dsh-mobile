不另建首页入口。13-settings.png 的「全部扩展　5 插件 · 4 任务」就是聚合入口。

## 已知差异（**决定不做**，附理由）

| 差异 | 设计稿 | 现状 | 为什么不做 |
|---|---|---|---|
| 代码块底色 | 两主题都用**深底** | 浅色下是浅灰底 | 底色写死在 **Vendor 依赖**里（`Vendor/swift-markdown-ui/.../MarkdownContent+SelectableText.swift:12`）。改它要连带把前景色也改（浅色下代码字是深色，硬改深底 = 深字压深底看不见），且这段是**全屏选中复制页共用**的。动 vendor 下次 `swift package update` 必冲突，收益不抵风险 |
| 新会话为什么不能选模型 | 03b composer 有「V4-Flash ⌄」 | 新会话 `selectedSessionId == nil`，`store.selectModel` 第一行就 `guard` 返回 | 不是 UI 问题，是 store 的契约：模型选择必须挂在会话上。新会话的模型 chip 做成**只读展示、去掉箭头**（不给假入口）；等会话建立后才可切。要让新会话也能选模型 = 改 store 逻辑，另开一刀 |
| 06/07「等待你操作」 | 05 报等待审批耗时 | 固定「暂无数据」 | `GatewaySessionStats` 无等待时长字段、事件流里也无审批事件类型。**不编数据**，标注未采集 |
| 07 多两段 | 设计稿四段 | 多 Token 用量 / 上下文 | **既有能力，不能砍**：这是用户在这台手机上判断「会话还能跑多久」的唯一入口 |
